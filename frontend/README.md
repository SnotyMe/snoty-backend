# Snoty Frontend V2

Tech Stack: Vue 3, Nuxt 4, NuxtUI 4, TypeScript, Vite

## Development Setup

### Installing Dependencies
```bash
pnpm install
```

### ESLint Setup (for JetBrains IDEs)
If you're using a JetBrains IDE, make sure to enable ESLint correctly.
1. Go to `Settings` > `Languages & Frameworks` > `JavaScript` > `Code Quality Tools` > `ESLint`.
2. Select `Automatic ESLint configuration`
3. Add `.json5` to the `Run for files` option. This will ensure proper linting for the Locale files.

### Running the Development Server
Now, you are ready to start the development server.

```bash
pnpm dev
```
